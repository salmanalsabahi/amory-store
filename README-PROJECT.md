# توثيق مشروع عموري ستور

هذا المستند يقدم نظرة شاملة عن تقنيات وهيكلية مشروع "عموري ستور".

## نبذة عن المشروع
عموري ستور هو متجر إلكتروني متكامل يوفر تجربة تسوق سهلة، مع ميزات إضافية مثل حجز الاستشارات، تتبع الطلبات، ولوحة تحكم للإدارة.

## التقنيات المستخدمة (Tech Stack)

### الواجهة الأمامية (Frontend)
- **React 19**: مكتبة بناء واجهات المستخدم.
- **TypeScript**: لضمان أمان الأنواع (Type Safety).
- **Vite**: أداة بناء سريعة.
- **Tailwind CSS**: إطار عمل لتصميم الواجهات.
- **React Router DOM**: لإدارة التنقل بين الصفحات.
- **Lucide React**: لأيقونات الموقع.
- **Motion (framer-motion)**: للرسوم المتحركة.
- **Recharts**: لتمثيل البيانات (الرسوم البيانية).

### الخلفية (Backend)
- **Node.js مع Express**: خادم للتعامل مع طلبات API (في `server.ts`).

### قاعدة البيانات والخدمات (Backend-as-a-Service)
- **Firebase Firestore**: قاعدة بيانات NoSQL لتخزين المنتجات، المستخدمين، الطلبات، والاستشارات.
- **Firebase Authentication**: لإدارة تسجيل دخول المستخدمين.

## هيكلية الملفات
- `src/`: يحوي كود التطبيق الأساسي (المكونات، الصفحات، الخدمات).
- `src/components/`: المكونات القابلة لإعادة الاستخدام (UI, Layout, Chatbot, etc.).
- `src/pages/`: صفحات الموقع المختلفة (Home, Store, ProductDetail, Cart, Consultation, Admin, etc.).
- `server.ts`: نقطة دخول الخادم (Express).
- `firestore.rules`: قواعد الأمان لمنصة Firebase Firestore.

## قواعد البيانات (Database Rules)
يستخدم الموقع Firebase Firestore لتنظيم البيانات:
- تحتوي قاعدة البيانات على مجموعات (Collections) لإدارة المنتجات، المستخدمين، الطلبات، الكوبونات، والاستشارات.
- تم تطبيق قواعد أمان صارمة (`firestore.rules`) لضمان خصوصية وحماية البيانات.

## كيفية التشغيل والتطوير
1. **التطوير المحلي**: قم بتشغيل الخادم المحلي باستخدام: `npm run dev`.
2. **الإنتاج (Production)**: يتم بناء المشروع باستخدام `npm run build` ثم التشغيل باستخدام `npm start`.
